# Reviewer instructions

Go through the rubric item by item. Report each problem as one finding:
- `issue`: what is wrong, concretely.
- `location`: the file and the quoted line.
- `severity`: `blocker` (false claim, wrong company/title, misread restriction),
  `major` (a real weakness a hiring manager would notice), `minor` (polish).
- `rubric_item`: the rubric number and name.

Report only real problems. Do not pad with praise or trivia. If the packet is clean
on an item, report nothing for it. An empty findings list is a valid answer.
