# weekly-review

1. Run `python jobbot.py weekly` (writes `data/weekly_review.md`).
2. Report the funnel: discovered -> shortlisted -> applied -> responses.
3. Report response rate by source and by role type.
4. Suggest threshold tuning only when there are at least 10 applications with outcomes.
5. Stop. You decide whether to change `targets.min_fit_score` or `companies.yaml`.
